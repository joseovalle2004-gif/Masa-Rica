# Masa Rica

Sistema web de gestión y venta de productos para Masa Rica, emprendimiento familiar dedicado a la elaboración y comercialización de empanadas y preparaciones tradicionales.

## Características

- Catálogo de productos y categorías.
- Carrito de compras.
- Registro e inicio de sesión de clientes.
- Gestión de pedidos.
- Panel de administración.
- Control de inventario.
- Métodos de pago.
- Notificaciones por correo electrónico.
- Base de datos SQLite.

## Tecnologías

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript

## Instalación

1. Descargar el repositorio.
2. Instalar las dependencias de requirements.txt.
3. Configurar las variables de entorno mediante .env.example.
4. Ejecutar las migraciones de Django.
5. Cargar los productos iniciales.
6. Iniciar el servidor de desarrollo.
